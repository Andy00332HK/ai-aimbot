# AI Aimbot（單機 FPS 輔助瞄準）

![Python](https://img.shields.io/badge/Python-3.10%2B-blue) ![CUDA](https://img.shields.io/badge/CUDA-12.x-green) ![License](https://img.shields.io/badge/License-MIT-yellow)

即時物件偵測輔助瞄準工具：擷取螢幕中央 ROI → YOLO11 偵測人形敵人 → 透明覆蓋層顯示偵測框 → 平滑移動滑鼠輔助瞄準。

> ⚠️ **重要聲明**：本工具**僅供單機／離線遊戲使用**。用於任何連線／多人遊戲皆違反遊戲服務條款、
> 可能導致帳號封鎖，並破壞其他玩家的體驗。使用者須自行承擔誤用責任。
> 本專案不含任何反偵測（anti-cheat bypass）功能，偵測過程全部透明顯示於畫面。

---

## 功能特色

- 🎯 **YOLO11 人形偵測**：COCO 預訓練權重直接使用，人形敵人（士兵、殭屍等）免訓練
- 🖥️ **置中透明覆蓋層**：網格、偵測框（綠）、鎖定框（紅）直接疊在畫面中央，**點擊穿透**不影響遊戲操作
- 🎛️ **圖形化控制面板**：所有參數即調即用，自動保存
- ⌨️ **兩種啟動模式**：按住啟動（HOLD，可綁 Shift／滑鼠側鍵）或開關切換（TOGGLE）
- 🧠 **頭部／胸口瞄準**：熱鍵即時切換
- ⚡ **RTX 4060 實測**：47 FPS 迴圈、推論 8–14ms，遊戲幀率幾乎不受影響
- 🔧 **後端自動降級**：TensorRT FP16 → PyTorch CUDA → CPU

## 系統需求

- Windows 10 / 11
- Python 3.10–3.13
- NVIDIA GPU（建議，純 CPU 亦可運作但較慢）

## 安裝

1. 安裝 [Python](https://www.python.org/downloads/)（勾選 *Add to PATH*）
2. 雙擊執行 **`install.bat`**（自動偵測 NVIDIA GPU 並安裝對應版本 PyTorch 與套件）
3. 執行 `python main.py`

首次啟動會自動下載 YOLO11n 權重（約 5.4 MB）至 `models/`。

## 使用方式

| 操作 | 說明 |
|---|---|
| **啟動輔助** | HOLD 模式：按住 Shift（或自訂的滑鼠側鍵）；TOGGLE 模式：按 F6 或點面板按鈕 |
| **頭部／胸口切換** | 面板單選鈕或 **F7** |
| **離開程式** | **F8** 或面板「離開」 |

建議遊戲使用「**無邊框視窗（Borderless Windowed）**」顯示模式；全螢幕獨佔模式會蓋住覆蓋層且可能無法擷取。

## 控制面板調校指南

| 設定 | 說明 | 建議 |
|---|---|---|
| **啟動模式** | HOLD＝按住才瞄準；TOGGLE＝切換開關 | FPS 建議 HOLD，反應直覺 |
| **按住鍵** | Shift / Ctrl / Alt / Caps Lock / 滑鼠側鍵 X1 X2 | 滑鼠側鍵最顺手 |
| **瞄準部位** | 頭部＝框頂+20%；胸口＝框頂+55% | 追蹤穩定性：胸口較不易抖 |
| **模型** | 快速(n)／精準(s) | RTX 4060 用 s 也綽綽有餘 |
| **推論尺寸** | 320 / 416 / 640 | 越小越快；640 最準 |
| **掃描範圍 ROI** | 螢幕中央偵測區邊長 | 越小越快、越專注近距離目標 |
| **偵測門檻** | 信心度下限 | 0.4–0.5；誤偵測多就調高 |
| **平滑度** | 每幀移動誤差的比例 | 0.3–0.5 自然；1.0＝全速貼點 |
| **滑鼠靈敏度** | 位移倍率（補償遊戲／系統靈敏度） | 拉不夠就調高，過頭就調低 |
| **單幀最大位移** | 每幀位移上限 | 防止瞬移，維持 60 即可 |
| **網格／偵測框／覆蓋層** | 顯示開關 | 錄影或實機遊玩時可只留偵測框 |

## 常見問題

**Q：滑鼠拉動距離不對／拉過頭？**
調整「滑鼠靈敏度」。SendInput 相對位移會受 Windows「加強指標精準度」與遊戲內靈敏度影響，倍率用來校正。

**Q：覆蓋層沒出現？**
遊戲改用無邊框視窗模式；或確認面板「啟用置中覆蓋層」已勾選。

**Q：效能不足？**
推論尺寸改 320、模型用 n、ROI 縮小；有 NVIDIA GPU 時確認面板右上顯示 `PyTorch CUDA`。進階使用者可 `pip install tensorrt` 啟用 TensorRT FP16（首次自動匯出，之後更快）。

**Q：偵測不到敵人？**
本工具使用 COCO「person」類別。非人形敵人（怪物、機器人）需要自行收集截圖微調模型（進階主題）。
